# Case: windows-log-search-basics

Windowsイベントログの検索・フィルタリングだけを対象にした、最小限の独立した
テスト — インシデントの筋書きも、攻撃のストーリーもない。2つのWindows
イベントログのエクスポートデータ(JSON Lines形式に変換済み、1行1イベント。
圧縮された状態で提供されるため、使用前に解凍が必要)が与えられ、目的を
絞った検索(イベントID、プロセスパス、アカウント名、時間による相関)で
特定の事実を見つける。

**評価対象のエージェントへ:** ここではなく、まず [AGENTS.md](AGENTS.md) を
開いてください。
