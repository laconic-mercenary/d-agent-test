# Case: dga-beacon-logclear

小さな貨物物流会社のディスパッチャーのワークステーションが、アルゴリズムで
生成された候補ドメインを次々と試して稼働中のコマンド&コントロールホストを
探し出そうとするマルウェアに感染する — 大半は何にも解決しないが、一部は
最終的に解決し、マルウェアはその結果のアドレスへ定期的なビーコン通信を
確立する。終了する前に、そのワークステーション自身のSecurityイベントログを
消去する。このケースは、エージェントが成功した1件の接続だけを挙げるのでは
なく、ドメイン生成パターンそのもの(件数、ランダム性、解決率)を特徴づけ
られるか、またログ消去が実際に何を削除し、何を削除しなかったのかを、
前提とせずに検証できるかを試す。

**評価対象のエージェントへ:** ここではなく、まず [AGENTS.md](AGENTS.md) を
開いてください。
