# Case: insider-dns-tunnel-exfil

小さなデータ分析コンサルティング会社の財務アナリスト — 顧客財務情報の共有
フォルダへの完全に正規のアクセス権を持つ人物 — が、そのファイル群を
アーカイブした後、約2時間かけてDNSトンネリング経由で、この環境の通信では
それ以外に一度も登場しないドメインへ持ち出す。このケースには外部の攻撃者も、
侵害されたアカウントも一切登場しない — 唯一の「攻撃」は、正規のアクセス権
では説明のつかないことを、正規のアカウントが行っている点にある。このケース
は特に、エージェントが「社員が何かファイルを圧縮した」で止まらず、一連の
流れ(準備 → 持ち出し経路 → 送信先)全体を追跡できるかを試す。

**評価対象のエージェントへ:** ここではなく、まず [AGENTS.md](AGENTS.md) を
開いてください。
