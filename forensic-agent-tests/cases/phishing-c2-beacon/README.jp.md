# Case: phishing-c2-beacon

小さな法律事務所のパラリーガルが、支払期限超過の請求書通知を装ったフィッシング
メールのマクロ付き添付ファイルを開く。そのマクロは隠れたPowerShellステージャー
を起動し、外部インフラへの定期的なHTTPSビーコン通信を確立する。約90分間の
通常のチェックイン通信の後、同じ通信路の中の1件の接続だけが、他のどのビーコン
通信よりもはるかに大きな通信量を示す — これはビーコン自体ではなく、C2通信路に
乗せられた攻撃者の手動操作である。このケースは特に、エージェントが侵入経路・
実行・C2確立を、3つの別個の、個別に証拠を示せる段階として追跡できるか、
また「ビーコンを見つけた」ことを調査の終わりとするのではなく、他とは違う
その1件の接続に気づけるかを試す。

**評価対象のエージェントへ:** ここではなく、まず [AGENTS.md](AGENTS.md) を
開いてください。
