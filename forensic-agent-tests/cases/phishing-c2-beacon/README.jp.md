# ケース

評価対象エージェント(AUT)を評価するためのデジタルフォレンジック調査
ケースです。シナリオ、手法、結果についての説明はこのファイルには
含まれていません — エージェントに必要な情報は [AGENTS.md](AGENTS.md)
を参照してください。

**評価対象のエージェントにこのケースを与える前に:** このケースの
ディレクトリ全体を、中立的な名前(例: `case-01`)の作業用ロケーションへ
コピーしてください。元のディレクトリ名がエージェントの目に触れないように
するためです。このディレクトリ内のファイルをエージェントが最初に読む前に、
必ず行ってください。

**評価対象のエージェントへ:** ここではなく、まず [AGENTS.md](AGENTS.md) を
開いてください。
