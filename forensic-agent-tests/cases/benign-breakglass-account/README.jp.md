# Case: benign-breakglass-account

小さな保険代理店で、オンコール担当の2人のシステム管理者が、複数のサーバーに
またがる正規に文書化された緊急用(break-glass)ローカル管理者アカウントを
共有している。使われるのは時間外のインシデント対応時のみで、変な時間帯の
ログオンとその後の診断用PowerShellコマンドという、単体で見れば不審に映る
パターンだが、実際には文書化された正規の運用手順と一致する。このケースに
攻撃は含まれない。エージェントが「インシデントなし」という結論に、実際の
検証(そのアカウントが何のために文書化されているかを確認し、無関係な深夜の
事象をそれ自体の内容から評価する)を通じて到達できるか、それとも通常の
時間外の管理作業を誤って警報に格上げしたり、何も確認せずにすべてを
見過ごしたりしてしまうかを試す。

**評価対象のエージェントへ:** ここではなく、まず [AGENTS.md](AGENTS.md) を
開いてください。
