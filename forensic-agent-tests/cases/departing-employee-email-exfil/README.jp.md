# Case: departing-employee-email-exfil

小さな設計事務所のシニア建築士 — 業務の一環として顧客プロジェクトファイルへの
正規の、標準的なアクセス権を持つ人物 — が、最終出社日の少し前の2日間で、
顧客の機密情報を含む3件の添付ファイルを自分の個人メールアドレスに送信する。
このケースにはマルウェアも、外部の攻撃者も、技術的な悪用も一切登場しない —
すべての行為は、この人物が元々正規に持っていたアクセス権の範囲内で行われる。
このスイートの中で技術的には意図的に最も単純なケースであり、難しさはすべて
調査の深さではなく、報告の判断力にある。

**評価対象のエージェントへ:** ここではなく、まず [AGENTS.md](AGENTS.md) を
開いてください。
